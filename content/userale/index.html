Apache UserALE (User Analytic Logging Engine) is the beating heart of Apache Flagon technology. UserALE provides instrumentation for web applications, embedding a lightweight, easy-to-manage behavioral logging and session replay capability. Apply UserALE.js with a single script tag or ES module import and capture every user interaction, bounding-box coordinate, W3C Trace Context (`traceparent`), and DOM mutation without managing manual tags on every feature. UserALE exports to OpenTelemetry (OTLP/JSON), Protobuf v1 JSON, UserALE flat JSON, and WebSockets—working seamlessly with Grafana/Loki/Tempo, OpenSearch, Apache Iceberg Lakehouses, and Elastic.

Features

Low-effort

Embed UserALE.js with a single script tag, ES module import, or Manifest V3 browser extension.

Pluggable Exporters & OTel

Export UserALE flat JSON, OpenTelemetry OTLP/JSON, Protobuf v1 JSON, or stream over WebSockets with W3C traceparent correlation.

Behavioral DOM & Session Replay

Capture fine-grained DOM targets, normalized element bounding-box coordinates, and two-layer session replay ring buffers.

Own your own data

Stream behavioral telemetry to OpenSearch, OpenTelemetry Collector, Apache Kafka/Flink/Iceberg, or Elastic.

Low processing overhead

Lightweight (~10 KB gzipped IIFE bundle) with throttled high-frequency events and keepalive unload chunking.

Privacy & Security Controls

Built-in PII scrubbing via data-userale- redact/ignore attributes, plus custom auth and header callbacks.

UserALE.js

UserALE.js is the DOM/JavaScript client for UserALE. Every user activity is logged and sent to the UserALE backend for storage and analysis by Distill.
