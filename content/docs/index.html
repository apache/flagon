About the Docs

The Apache Flagon documentation is organized by component and covers client-side telemetry collection, behavioral analytics, and full-stack observability deployments:

  • Reference Architectures & Deployments: Turnkey Docker Compose stacks for OpenTelemetry + Grafana (Loki + Tempo), OpenSearch + Dashboards, Apache Lakehouse (Kafka + Iceberg + Spark + Superset), and Elastic Stack (ELK).
  • Apache Flagon UserALE.js: Frontend behavioral telemetry, OpenTelemetry OTLP/JSON & Protobuf v1 exporters, W3C TraceContext correlation, DOM mutation & rage-click detection, and two-layer session replay (rrweb).
  • Apache Flagon Distill: Python behavioral analytics framework for multi-format UserALE schema validation, UX frustration & spatial analytics, clickstream graphs, Markov transition matrices, and session segmentation.
  • Contributing Guide: Monorepo setup with Nix, pnpm, uv, and buf.
