UserALE.js Build and Test

To build and test Apache Flagon UserALE.js, clone the apache/flagon monorepo and ensure you have Node.js (>= 20.x) and pnpm (>= 10.x) installed (or run nix develop at the repository root).

git clone https://github.com/apache/flagon.git
cd flagon/products/userale

# Install workspace dependencies
pnpm install

Build

UserALE.js is written in TypeScript and bundled with tsup (producing both ES module build/main.mjs and script-tag IIFE build/main.global.js bundles alongside TypeScript declarations build/main.d.ts), while the browser extension (flagon-userale-ext) is built with Plasmo.

# Build all workspace packages (flagon-userale and flagon-userale-ext)
pnpm build

# Or build only flagon-userale
pnpm --dir packages/flagon-userale build

If you modify proto/apache/flagon/userale/v1/log.proto, regenerate the TypeScript Protobuf contract definitions from the repository root:

buf lint
buf generate

Test

UserALE.js uses Jest (with jsdom and @bufbuild/protobuf contract tests) for unit testing and Playwright for end-to-end browser and extension testing.

Run Unit & Schema Contract Tests (Jest)

pnpm --dir packages/flagon-userale test
